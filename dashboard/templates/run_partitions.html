How to read this tab

Every arm splits the val and test rows into groups, reading none of their labels. A group predicts, for each of its test rows, the failure rate of its own val rows (the global val rate if it has none); the scores say how well those predictions match the test failures.

Arms

intra
k-means inside each class of train; each val and test row joins the nearest centre.
inter
k-means over all of train, routed the same way.
null
random cells instead of k-means, the mean of its draws: the floor, since an arm that does not beat it at a similar group count learns nothing from the geometry. It picks its own level, so its group count is not inter's.
confidence
equal-val-mass bins of the classifier's top probability, over all rows.
predicted_class
the same bins, inside each predicted class.
rule
selected is the grouping of least loss; fixed15, cbrt and per150 are 15 bins, the cube root of the val rows, and one bin per 150 of them.

Scores, on test

Brier
mean squared gap between the predicted rate and each row's failure (0 or 1); lower is better.
reference Brier
the same for one global val rate on every row, the group-blind answer.
skill
1 − Brier / reference Brier: 0 is no better than the global rate, 1 is perfect, below 0 is worse.
resolution
how far the groups' test rates sit from the overall one, i.e. how well they separate failing from correct rows; higher is better. It grows with the group count even for random groups, so compare arms at similar counts.
reliability
how far each group's val estimate sits from its test rate, i.e. how little the estimate transfers; lower is better.
identity
Brier = uncertainty − resolution + reliability; uncertainty is the same for every arm, so the arms differ in resolution and reliability only.
AUROC
the chance that a failing test row gets a higher predicted rate than a correct one; 0.5 is chance.
kDN Spearman
geometric arms only: the rank correlation of each group's mean train hardness with its test rate.
no val
the share of test rows in a group with no val row.
